# SecondSelf Architecture

## Overview
SecondSelf is a knowledge management system that captures, classifies, links, visualizes, and queries personal knowledge. The architecture is divided into four phases, each building on the previous to create a self-organizing knowledge graph.

## System Components

### 1. Capture Pipeline (Week 1)
**Component**: `capture.py`
- **Functionality**:
  - Accepts any input (text, link, file)
  - Generates unique ID (UUID4) and timestamp
  - Saves raw content to `raw/{uuid}.txt` (text) or `raw/{uuid}.bin` (files)
  - Creates metadata JSON with: `uuid`, `timestamp`, `content_type`, `source`
- **Storage**:
  - `raw/` directory with timestamped subdirectories
  - Metadata stored in `raw/metadata.json`

### 2. Classification & Linking (Week 2)
**Components**:
- **`classify.py`**:
  - Uses LLM (Groq/Llama3) API to analyze raw content
  - Returns PARA category, tags, and summary
  - Updates metadata with classification results
- **`link.py`**:
  - Computes embeddings using `sentence-transformers`
  - Stores embeddings in `wiki/embeddings/` (Pinecone/FAISS)
  - Compares new embeddings against existing ones (threshold: 0.75)
  - Creates bidirectional links in `wiki/links.json`

### 3. Graph Visualization (Week 3)
**Components**:
- **`build_graph.py`**:
  - Reads `wiki/` notes and `wiki/links.json`
  - Creates JSON graph with:
    - Nodes: `{id, title, category, summary}`
    - Edges: `{source_id, target_id, strength}`
  - Exports to `graph.json`
- **Frontend**:
  - Uses Cytoscape.js for interactive visualization
  - Features:
    - Force-directed layout
    - Hover tooltips with note content
    - Zoom/pan controls
    - Node highlighting

### 4. Knowledge Querying (Week 4)
**Components**:
- **`ask.py`**:
  - Implements retrieval-augmented generation (RAG)
  - Steps:
    1. Convert question to embedding
    2. Find top-k similar notes (Pinecone)
    3. Retrieve content from `wiki/`
    4. Use LLM to synthesize answer
- **Streamlit App (`app.py`)**:
  - Combines:
    - Graph visualization (Cytoscape)
    - Search interface (text input + submit button)
  - Deployed via Streamlit Cloud

## Data Flow
1. **Capture** → `raw/` → **Classification** → `wiki/` → **Linking** → `wiki/links.json` → **Graph** → `graph.json` → **Querying** → Streamlit UI

## Tech Stack
- **Backend**: Python (FastAPI for API endpoints)
- **LLM**: Groq/Llama3 via API
- **Embeddings**: Sentence-Transformers + Pinecone
- **Graph**: Cytoscape.js
- **Deployment**: Streamlit Cloud

## Security
- End-to-end encryption for sensitive notes
- Role-based access control (admin/user)
- Regular backups to S3

## Testing Strategy
- Unit tests for each component
- Integration tests for full pipeline
- User testing with 10+ real notes
